## Installation contract and limits

An explicit native **YOOtheme Style Save is required after installation or update**. Beta updating retained existing compiled CSS. A separate browser save compiled/reopened a changed colour and produced the expected section/button/text values. Automatic existing-CSS regeneration is not claimed.

Qualification covers the exact lanes above, a PHP development server, inherited parent Builder templates and native file-cache clearing with global caching disabled. Joomla 5, other PHP versions, arbitrary Builder-template overrides, all full-page-cache configurations and future vendor internals need separate qualification. Ordinary per-render callbacks are covered. Persistent original-element mutation and dynamic callback-list changes remain outside the adapter contract.

## Next steps

Install on the intended site when authorised, enable the plugin and perform the explicit native Style Save. No further qualification or release action is required for this version. Requalify the documented contracts before supporting another vendor/runtime version.
