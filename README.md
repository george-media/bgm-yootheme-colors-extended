# BGM YOOTheme Colors Extended

An original Joomla system plugin project for extending YOOtheme Pro's colour choices.

**Status: discovery and architecture. No installable BGM plugin has been released yet.**

The intended first build adds Tertiary, Quaternary, Quinary and Senary colour families to the native style editor and applicable Builder controls. The existing KickYOOcolors 1.2.2 package is a behavioural reference only. Its implementation is not being repackaged.

The current target is YOOtheme Pro 5.0.52, checked against the [official changelog](https://yootheme.com/changelog) and an installed local copy on 18 October 2026. Runtime compatibility remains untested.
